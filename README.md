# VL - Perfume (React)

This is a React + Vite recreation of [`https://vyvo.life/`](https://vyvo.life/) 

## Preview locally

From the `vyvo` folder:

```bash
npm install
npm run dev
```

Open:

- `http://localhost:5175`

## Notes

- The 3D bottle uses Three.js loaded from a CDN at runtime.
- The “Add to cart” and contact form are front-end only (no backend wired).
